# deploy_agent

A shell script (`deploy_agent.sh`) that deploys, runs, and archives the logs of the
**Student Attendance Tracker** Python application.

`templates/` holds the three unmodified source files the script deploys:

- `attendance_checker.py` – the interactive marking tool
- `assets.csv` – sample roster of 10 students (4 prior sessions each)
- `config.json` – alert thresholds and session count
